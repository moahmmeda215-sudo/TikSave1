# TikSave

TikSave هو موقع لتحميل فيديوهات TikTok بسهولة.

## المميزات

* تحميل فيديوهات TikTok
* جودة 1080p
* جودة 720p
* جودة 480p
* جودة 360p
* تحميل الصوت MP3
* واجهة عربية ومتجاوبة

## التشغيل

```bash
pip install -r requirements.txt
python Tiksave_optimized.py
```

## التقنيات

* Python
* Flask
* yt-dlp
* FFmpeg
